# Eski tek dosyalık site

Bu klasördeki `index.html`, depodaki ilk sürümdür: veritabanı ve sipariş
sistemi olmayan, menüsü HTML içine gömülü tek dosyalık statik site.

Yerine gelen tam uygulamanın (sipariş alma + yönetim paneli) kurulumu için
kökteki [README.md](../README.md) dosyasına bakın.

Buradaki dosya yayına alınmaz; referans olarak saklanmıştır. Silmek
isterseniz bu klasörü tamamen kaldırabilirsiniz.
